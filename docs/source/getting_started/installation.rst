============
Installation
============

Django GenFKAdmin is a python library, which can be installed in the following
ways.

------------
PyPI package
------------

Django GenFKAdmin packages are published on the
`Python Package Index <https://pypi.org/project/django-genfkadmin/>`__ (PyPI).
You can use which ever package manager you prefer to install.

with pip::

   $ pip install django-genfkadmin

with uv::

   $ uv install django-genfkadmin

-------------------
Install from source
-------------------
You probably don't want to do this, but if you do need to install from the main
branch or some other commit you can point your install at github.

with pip::

   $ pip install git+https://github.com/mikespallino/django-genfkadmin
